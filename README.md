# ns_radialmenu

A customisable radial menu for FiveM roleplay servers, by **Neutral Studios**.

Three themes, a per-character settings page, vehicle and clothing controls, smart blips, a trunk and kidnapping system, and job menus for Police, EMS, Mechanic, Taxi and Tow.

Works with ESX, QBCore, QBox and standalone.

## Get it

**[Download on Tebex](https://store.neutral-studios.com/package/7686751)**

This repository is for information and issues only — the resource itself is distributed through Tebex.

## Requirements
- [ox_lib](https://github.com/overextended/ox_lib)
- [oxmysql](https://github.com/overextended/oxmysql)

## Install

1. Download from Tebex and drop `ns_radialmenu` into your resources folder
2. Start `ox_lib` and `oxmysql` before it
3. Add `ensure ns_radialmenu` to your `server.cfg`
4. Edit `config.lua` to suit your server

The database table is created automatically on first start.
